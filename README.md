# PortScannerListener/Мониторинг подключений к портам

## Описание
Консольное приложение на языке C#, предназначенное для асинхронного мониторинга входящих сетевых подключений в заданном диапазоне портов. Инструмент поддерживает протоколы TCP и UDP.

## Функциональные возможности
- Выбор протокола мониторинга: TCP или UDP.
- Задание пользовательского диапазона портов (от 1 до 65535) с встроенной валидацией входных данных.

## Системные требования
- .NET SDK 6.0 или выше.

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd <ИМЯ_ПАПКИ_ПРОЕКТА>
   ```
2. Восстановите зависимости и соберите проект:
   ```bash
   dotnet build
   ```
3. Запустите приложение:
   ```bash
   dotnet run
   ```
4. Следуйте инструкциям в консоли:
   - Введите `1` для выбора TCP или `2` для выбора UDP.
   - Укажите начальный порт.
   - Укажите конечный порт.
5. Для завершения работы приложения используйте комбинацию клавиш `Ctrl+C`.
